# Third-party components and data

The project source has an MIT license. Dependency and model licenses are separate; no package or model is relicensed by this repository. Native library code/model weights are downloaded separately and are not included in this source pack. Fixtures are synthetic project examples, not a real-world benchmark dataset. Application code does not upload camera images; third-party runtime/network behavior has not been independently audited.

MediaPipe and the Google gesture-recognizer model bundle are credited to Google and their upstream contributors. Check the model card and applicable notices before distribution. The app uses their pretrained model; it did not train the seven-category classifier. Pinch event/calibration code is separate application logic.
